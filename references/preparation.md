# 接入前准备

本文档说明接入盛付通 H5 快捷支付前需要完成的准备工作和需要获取的要素。

## 商户资质与账号

| 准备项 | 说明                                 | 获取方式 |
|--------|------------------------------------|----------|
| **商户号（mchId）** | 盛付通平台分配的商户唯一标识，所有接口必传              | 在盛付通平台完成商户开户/进件后获得 |
| **应用ID（appId）** | 快捷支付产品的应用标识，如 `213124324234213213` | 向盛付通运营申请快捷支付产品，审核通过后分配 |

## 密钥准备

### 商户侧

| 密钥 | 用途 | 说明 |
|------|------|------|
| **商户私钥** | 用于对 API 请求加签 | 商户自行生成并保管，在盛付通商户平台（https://b.shengpay.com）上传对应公钥。支持 RSA、RSA2 两种算法 |
| **商户公钥** | 提供给盛付通，用于验签商户请求 | 在商户平台上传，绑定到 mchId 下 |

### 盛付通侧

| 密钥 | 用途 | 说明 |
|------|------|------|
| **盛付通公钥（钱包公钥）** | 商户用于：① 加密付款人敏感信息（姓名/身份证号）② 验签盛付通的回调通知 | 联系盛付通获取（测试/生产环境各有一套） |

### 算法选择

| 算法 | signType 值 | 说明 |
|------|-------------|------|
| RSA | `RSA` | SHA1withRSA |
| RSA2 | `RSA2` | SHA256withRSA |

> 新接入商户推荐使用 **RSA2**，安全性更高。

## 环境信息

| 环境 | 说明 |
|------|------|
| **测试环境** | 用于开发联调，联系盛付通运营获取接口地址和测试 appId |
| **生产环境** | 联系盛付通运营获取接口地址 |

完整接口 URL = `https://{base_url}` + 接口路径。示例：`https://{base_url}/api/v3/payment/unifiedorder`

## 商户需提供的回调地址

| 回调地址 | 用途 | 在哪个接口传入 |
|----------|------|---------------|
| **支付通知 notifyUrl** | 接收支付结果异步通知 | 统一下单接口 `notifyUrl` 参数 |
| **退款通知 notifyUrl** | 接收退款结果异步通知 | 退款接口 `notifyUrl` 参数 |
| **bindCardEventNotifyUrl** | 接收用户绑卡/解绑事件通知 | 统一下单 `extra.bindCardEventNotifyUrl` 或获取卡管理URL接口 `notifyUrl` 参数 |

> 所有回调地址必须是**公网可访问**的 URL（生产环境强制 HTTPS，测试环境可 HTTP）。

## 接入检查清单

在开始联调前，请确认以下全部就绪：

- [ ] 已获取 mchId 和 appId
- [ ] 已生成商户 RSA/RSA2 密钥对
- [ ] 已在盛付通商户平台上传商户公钥
- [ ] 已获取盛付通公钥（测试环境）
- [ ] 已获取测试环境接口地址
- [ ] 已准备好公网可达的 notifyUrl（支付通知）
- [ ] 已准备好公网可达的退款 notifyUrl（如需退款）
